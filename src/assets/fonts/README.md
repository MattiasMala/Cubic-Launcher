# Material Symbols Outlined

`material-symbols-outlined.woff2` is Google's Material Symbols Outlined
variable font (axes `wght` 100–700 and `FILL` 0–1), the same file
`fonts.googleapis.com` served to the launcher before D159.

It ships with the app so the icons draw without a network (D140, D159).
